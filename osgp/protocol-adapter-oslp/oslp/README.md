# Oslp.java and Google protobuf

This is generated using an older version of the protobuf compiler. If you compile it with a newer version you will get 
some differences with the current Java file. Therefore: !Please do not delete this file! This version is used in 
production devices. 

If for some reason the file is deleted, then you can generate the java file again using the protobuf documentation for 
java:
https://github.com/protocolbuffers/protobuf/tree/main/java

For an older version of the protobuf compiler (protoc) look here: https://repo1.maven.org/maven2/com/google/protobuf/protoc/

The current runtime version of protobuf being used is `2.4.1`. The jars for this version can still be found here:
https://repo1.maven.org/maven2/com/google/protobuf/protobuf-java/2.4.1/

As a backup, these runtime files are backed up to the Alliander Artifactory. This Artifactory is online accessible for 
Alliander employees.
