# Oslp.java and Google protobuf

This is generated using an older version of the protobuf compiler. Version `2.4.1` to be exact. If you compile it with a 
newer version you will get some differences with the current Java file. Therefore: !Please do not delete this file! 
This version is used in production devices. 

If for some reason the file is deleted or needs to be modified, then you can generate the java file again using the 
protobuf documentation for java: https://github.com/protocolbuffers/protobuf/tree/main/java.

For the older version of the protobuf compiler (protoc) that was used to generate the current `Oslp.java` file look here:
https://github.com/protocolbuffers/protobuf/releases/tag/v2.4.1.
There is a pre-compiled Windows version, for Linux and Mac you must generate the compiler from the sources yourself. 

The current java-runtime version of protobuf being used is `2.4.1`. The jars for this version can still be found here:
https://repo1.maven.org/maven2/com/google/protobuf/protobuf-java/2.4.1/.
